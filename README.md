# Airlock Launcher 4.2.0

1. **Скачай и установи** [.NET SDK 10 (Windows x64)](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) и [PowerShell 7 (Windows x64 MSI)](https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-windows). На GitHub нажми **Code → Download ZIP** и распакуй архив проекта.
2. **Собери.** Открой папку с `Build-Dev.ps1`. В адресной строке Проводника набери `pwsh`, нажми Enter и выполни:

   ```powershell
   pwsh -File .\Build-Dev.ps1
   ```

3. **Запусти** `dist\Airlock Launcher - Dev\Airlock Launcher.exe`.
